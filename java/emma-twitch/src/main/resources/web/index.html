Bit Cheer Tiers

When a viewer cheers bits, the highest matching tier triggers its effect. For example, if you set 100 bits = "zombie" and 500 bits = "explode", a 200-bit cheer triggers "zombie" and a 600-bit cheer triggers "explode".

How Viewers See Rewards

Channel Point rewards appear in the reward menu (gift icon below the chat input). Viewers click a reward, it deducts their points, and triggers the mapped effect in-game. You create rewards in your Twitch Creator Dashboard under Viewer Rewards → Channel Points → Custom Rewards.

Bits cheers work differently — viewers type cheer100 (or use Bit emotes) in chat. The mod matches the bit amount against your configured tiers.
